# Página Tributo a Neymar Jr.

Proyecto de una página tributo desarrollado como parte del curso de **Diseño Web Adaptable** de [freeCodeCamp](https://www.freecodecamp.org/).

## 🚀 Tecnologías utilizadas
* HTML5
* CSS3

## 📌 ¿Qué incluye?
* Estructura semántica con HTML (`main`, `h1`, `div`, `figcaption`, etc.).
* Estilos CSS personalizados y diseño adaptativo para la imagen.
* Enlace externo informativo.
